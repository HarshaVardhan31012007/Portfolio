1. Executive Summary

This project extends the React Portfolio Website built in Assignment 2 by integrating a fully functional Node.js / Express REST API backend located in the /server directory. Hardcoded static projects and client-side contact submission have been transitioned to dynamic backend API endpoints with JSON file persistence, server-side validation, CORS, and comprehensive error handling.

2. Backend Tasks Evaluation Matrix (B1–B7)

Task Endpoint / Resource Method Status Evaluation Specification & Implementation Details
B1 / GET Complete Health check route returning HTTP 200 {"status":"ok"}. Server port loaded from PORT in .env.
B2 /api/projects GET Complete Serves array of 4 projects from server/data/projects.json retaining all props expected by ProjectCard.

B7 CORS & Env - Complete Configured cors for http://localhost:5173. Provided .env.example with zero secrets committed.

4. Execution & Startup Commands

The application runs using two documented commands:

npm run server

# 2. Start React Frontend Dev Server (http://localhost:5173)
npm run dev
